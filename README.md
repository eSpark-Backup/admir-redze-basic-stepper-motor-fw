## Project Requirements
### Components
1. Arduino UNO
2. [Arduino Motor Shield REV3](https://store.arduino.cc/products/arduino-motor-shield-rev3) 
3. Power supply 12V - 1,5 A
4. [Arduino Shield - Display LCD kit, 16x2](https://www.reichelt.at/at/en/arduino-lcd-shield-kit-16x2-blue-and-white-display-arduino-shd-lcd-p159967.html?CCOUNTRY=458&LANGUAGE=de&GROUPID=9005&START=0&OFFSET=16&SID=93cb780cad82a0a846988edadae8669e557d25e97874e667283aa&LANGUAGE=EN&&r=1)

### Task
Control a stepper motor in CW and CCW with 1 turn in 1.5 second in each direction and 0.5 second brake / pause in between each turn. The LCD display should count each turn and show this info to the user. For ON/OFF, a simple switch is being used.
